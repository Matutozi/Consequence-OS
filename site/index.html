ConsequenceOS

source · docs · download

If you let an AI agent issue refunds, edit code or touch a database, you need to decide what it may do on its own and what needs a person first. ConsequenceOS lets you write that down as rules, and enforces them on every call the agent makes.

Small things go through. Risky things wait for someone to approve them. Anything you've ruled out is refused. And every call that goes through carries a signed receipt, so the system on the other end can check it was really allowed.

How you use it

1. Write your rules. For example, an agent that handles customer refunds:

rules:
  - name: small-refunds
    tool: payments.refund
    when: { arg: amount, op: lte, value: 50 }
    action: allow

  - name: everything-else-asks
    tool: payments.refund
    action: ask

2. Put ConsequenceOS in front of your tools. Your agent connects to ConsequenceOS instead of your tool server, and ConsequenceOS passes on the calls your rules allow. The agent never holds the tool server's credentials, so it can't go around it.

3. Let the agent work.

  • It refunds $20: the call goes straight through.
  • It tries to refund $5,000: the call is held, and an approver gets an email. Once they approve, that exact refund goes through, once.
  • Every decision is written to an audit log that shows if anyone edits it.

4. Optional: have your service check receipts. Add the receipt check to your API (there's middleware for Go and Python), and it will refuse any call that didn't come through ConsequenceOS.

The quickstart runs this refund example on your machine with Docker in about ten minutes.

Or try it on Claude Code

The same rules can guard a coding agent. Install the plugin in Claude Code:

/plugin install consequenceos --marketplace Matutozi/Consequence-OS

From then on, Claude can read files and edit your project freely, asks you before running shell commands, and can't touch your .env files, SSH keys, or the guard itself. You change any of that by editing the rules. See ConsequenceOS on your own machine.

Good to know

  • It doesn't try to detect prompt injection. It limits what an agent can do, however it was misled.
  • It works with tools reached through MCP, and with Claude Code's own tools. Linux and macOS.
  • It's early, open source, and built by one person. If something breaks, please open an issue.
