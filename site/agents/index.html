Agent Cards

Each file here is the Agent Card of an agent registered in Concordium's Agent Registry and guarded by ConsequenceOS. The registry pins each card's URL and SHA-256, so the files are hosted exactly as consequence-anchor card wrote them. To check an agent from the chain, run consequence-anchor verify -token ID.
